
# API Reference

The Sbarter Publisher Integration consists of two API
interfaces, each with a different implementation responsibility.

## Sbarter API

Endpoints hosted by Sbarter and called by game studios.

These include player account linking, linking status,
and contest result submissions.

[View Sbarter API](/server)

## Game Studio API

Endpoints that game studios must implement and expose
to Sbarter.

These include in-app account linking confirmation,
player profile retrieval, and game session registration.

[View Game Studio API](/client)

For step-by-step implementation instructions,
see the [Integration Guides](/guides/).
